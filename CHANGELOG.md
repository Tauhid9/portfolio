# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and follows Semantic Versioning.

## [0.2.0] - 2026-08-12
### Added
- Cancellable, distance-aware cubic ease-out scrolling for same-page navigation
- Focused unit tests for scroll easing, timing, sticky-header clearance, and document bounds

### Changed
- Back-to-top now uses the same accessible anchor-scrolling path as the rest of the site
- CI now runs the automated test suite before the production build
- Architecture and setup documentation now match the current homepage structure

## [0.1.0] - 2026-07-30
### Added
- Comprehensive repository documentation set for long-term human and AI collaboration
- Real screenshot galleries for multiple portfolio projects
- Project gallery helper logic and local project asset organization
- Skills section redesign with richer presentation hierarchy
- Education achievements display
- GitHub repository governance files and CI scaffolding

### Changed
- Replaced stock project visuals with polished real product screenshots
- Standardized repository configuration for linting, type checking, and CI
- Cleaned environment example handling to avoid exposing secrets

### Fixed
- Supporting skills cards visibility issue in the Skills section

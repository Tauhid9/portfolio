  QUICK SETUP - Get Emails Working in 3 Minutes
═══════════════════════════════════════════════════════════════

STEP 1: Enable 2-Step Verification
→ Go to: https://myaccount.google.com/security
→ Click "2-Step Verification" → Get Started → Follow steps

STEP 2: Generate App Password  
→ Go to: https://myaccount.google.com/apppasswords
→ Select "Mail" and your device type
→ Copy the 16-character password Google shows

STEP 3: Create .env.local File
→ Create new file in project root: .env.local
→ Copy this (replace with your info):

GMAIL_USER=tauhidhasan2017bd@gmail.com
GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx

STEP 4: Restart & Test
→ Save .env.local
→ Restart your dev server
→ Test the contact form
→ Check your Gmail inbox!
